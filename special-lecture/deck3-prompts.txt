Prompt 1

Write a short PLAN.md in this empty folder for a tiny local web app called Stock Desk Mini. Rules: only Python 3 standard library, no pip installs, no npm, no other packages. One web page: pick one of three indexes (S&P 500, Nasdaq Composite, Dow Jones Industrial Average), see a line chart of its last 6 months of daily closing prices with its 20-day and 50-day moving averages, and one reading of BUY, SELL, or HOLD. Trend is price versus the 50-day average, momentum is 14-day RSI versus 50, and the trigger is the day's close breaking above the prior 5 trading days' high or below the prior 5 trading days' low. Data must be free, need no account and no API key: use the FRED fredgraph.csv endpoint, for example https://fred.stlouisfed.org/graph/fredgraph.csv?id=SP500 for the S&P 500, id=NASDAQCOM for Nasdaq, id=DJIA for Dow. A browser page cannot fetch that URL directly, so a small Python server must fetch the CSV itself and hand the page JSON. List the exact files you will create and how the BUY, SELL, HOLD reading is computed. Do not write any code yet, only the plan.
